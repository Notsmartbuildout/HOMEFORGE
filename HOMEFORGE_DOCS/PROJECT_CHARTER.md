# HOMEFORGE

Local-first homeowner renovation modelling: capture, correct, verify, modify, measure.

Start with one renovation space, not a whole-house survey. First practical project: front entry and stairs; basement and bathroom follow.

Initial scope combines V1 and V1.5: project dashboard; manual geometry; photo/floorplan underlays; compatible RoomPlan file import; numeric dimensions; drag/snap/resize/rotate; 2D, elevation, 3D; baseline and design alternatives; measurement provenance; notes/photos; local persistence; dimensioned export and portable backup.

Preserve upstream editing and geometry infrastructure. No Python, AI, native scanner, structural calculations, automatic photo reconstruction or code-compliance engine in the initial release.

Success: a homeowner can reproduce measured conditions, create an independent proposed option, inspect it in useful views, and export dimensions with their provenance visible. Manually measured dimensions do not constitute structural or code approval.
